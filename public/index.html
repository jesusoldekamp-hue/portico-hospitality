Arquitectura Escala Nacional (Lista para 1,000 Hoteles)

PostgreSQL 16 + Row-Level Security (RLS), cifrado AES-256-GCM y prueba criptográfica en vivo.

  • Aislamiento físico PostgreSQL RLS (sql/schema.postgres.sql): Política ENABLE ROW LEVEL SECURITY por RFC + soporte Multi-Asociación y purga automática LFPDPPP (purge_expired_guest_pii).
  • Adaptador dual SQLite ↔ AWS RDS (src/db-adapter.js): Corre sin dependencias en piloto y escala horizontalmente con docker-compose.prod.yml (PostgreSQL 16 + Redis 7 + SQS Workers).
  • Despliegue masivo sin fricción: Instalador Windows/Linux de 1 clic preconfigurado por hotel en la pestaña Conectores PMS.

Cómo protege Certeza ID al personal de recepción

  • Aislamiento RBAC real en servidor: Cuando el recepcionista inicia sesión, el servidor le bloquea con HTTP 403 cualquier acceso a alertas SEGOB, bitácoras de auditoría u otros hoteles.
  • Cero exposición a riesgos físicos: Si el huésped o menor tiene un reporte activo en SEGOB, esta pantalla no muestra alarmas rojas; la notificación viaja en segundo plano a la cola Outbox hacia SEGOB.
  • Cumplimiento automático con menores: En cuanto la CURP indica menos de 18 años, Certeza ID despliega el control obligatorio de la Ley General de Turismo y deja constancia auditable.
